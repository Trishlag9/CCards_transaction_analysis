# 💳 Credit Card Transactions Analysis (SQL Project)

## 📌 SQL Analysis Summary

This project answers the following business questions using advanced SQL:

1. **What are the different card types available in the dataset?**

2. **What is the range (start and end date) of the credit card transactions in the dataset?**

3. **Which are the top 5 cities with the highest total credit card spend?**
   - What is the percentage contribution of each city to the total spend?

4. **For each card type, which month had the highest spending?**
   - Also, how much was spent in that month?

5. **At what transaction (record) did each card type cross ₹10,00,000 in cumulative spending?**
   - Return all transaction details for each of these 4 card types.

6. **Which city contributed the least percentage to the total Gold card spends?**

7. **For each city, what is the highest and lowest spending expense type?**
   - Example output format: `Delhi | Bills | Fuel`

8. **What is the percentage contribution of female customers for each expense type?**

9. **Which card type and expense type combination saw the highest month-over-month growth in January 2014?**

10. **During weekends, which city had the highest total spend to transaction count ratio?**
    - (i.e., which city spends the most per transaction on weekends?)

11. **Which city reached 500 transactions in the shortest number of days from its first transaction date?**
